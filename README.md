## เกี่ยวกับโปรเจกต์

เว็บแอปสำหรับค้นหาความหมายภาษาไทยจากคำศัพท์ภาษาอังกฤษ จัดเก็บคำที่ค้นหาไว้ทบทวน และดูสถิติการเรียนรู้ ใช้พจนานุกรมจากไฟล์ TSV ภายในโปรเจกต์ พร้อมบันทึกข้อมูลไว้ในเครื่อง ไม่ต้องสมัครบัญชีหรือเชื่อมต่อบริการแปลภาษาออนไลน์
